# Scent Map identity

A single flowing S suggests a scent trail and a route on a map. The warm accent
at its endpoint adds a quiet point of orientation. Pair the mark with the light
serif wordmark and generous space.

- `scent-map-mark.svg`: app mark, for sizes of 32 px and above.
- `scent-map-logo.svg`: horizontal logo on light backgrounds. Live text uses Georgia and Arial with system fallbacks.
- `../favicon.svg`: the same silhouette with a heavier stroke for 16-32 px browser tabs.

Palette: deep green `#304b43`, ivory `#faf8f3`, warm accent `#d4ad80`.
Wordmark: ink `#25211c`; secondary text: `#746c62`.

Preserve the proportions and leave at least one quarter of the mark's width as
clear space. Avoid extra outlines, shadows, or decorative nodes around it.
The app uses HTML for the wordmark and decorative images with empty alt text,
so screen readers announce the name only once.
